# Portfolio

A personal portfolio site for Medjahri Mohammed Safouane, an AI & Data Science engineering student, aimed at internship and PFE (final-year project) applications.

## Language

**Project**:
A body of work the site presents. Every Project gets a full page telling the story from problem to result, including the research behind it, the approaches compared, and the owner's contribution; a Project may span more than one Repository.
_Avoid_: Case study, repo, codebase, portfolio entry

**Full title**:
The complete Project name, used as the page `<h1>` and the metadata title. H-GATE's full title, for example, is “H-GATE: Harris-Hawks-Optimized Gradient-boosted Attention-Transformer Ensemble.”
_Avoid_: Page title, heading, long name

**Short title**:
The compact Project name (`shortTitle`) used on cards, the breadcrumb, and previous/next navigation. It is the name a visitor sees before opening the page.
_Avoid_: Card title, alias, nickname

**Research & prior art**:
The papers and methods a Project builds on, each with a citation and a takeaway that says what it changed. It is not a reading list.
_Avoid_: Bibliography, references, literature review

**Approaches compared**:
The alternatives that were seriously considered, each with strengths, limits, and a verdict. It includes the option that lost.
_Avoid_: Options, alternatives, model comparison

**Personal contribution**:
The concrete work the owner built, separated from a teammate's work when the Project is a team effort.
_Avoid_: My role, responsibilities, ownership (as a vague label)

**Featured Project**:
One of the four Projects shown on Home. The other Projects are reachable through "Show all projects" and the Projects index.
_Avoid_: Selected Project, main Project, flagship

**Repository**:
A Git code container on GitHub. It is a link target, never the unit the site presents.
_Avoid_: Repo, project, source

**Publication Status**:
Whether a Project’s code is publicly reachable, pending publication, or private. Unpublished entries stay in frontmatter but are omitted from the rendered page.
_Avoid_: GitHub status, link status

**Education**:
Degrees and the baccalaureate, including the ESI-SBA preparatory and engineering cycles.
_Avoid_: Studies, schooling

**Experience**:
Professional roles and internships, including the CTS Arzew network internship and the Zenith Academy teaching role.
_Avoid_: Work history, career

**Leadership & extracurricular**:
Student-club offices and extracurricular responsibilities, kept separate from professional Experience.
_Avoid_: Activities, volunteering, clubs (as an umbrella term)

**Certification**:
A credential issued by an external body. Certifications and awards have their own About section, which stays hidden while the list is empty.
_Avoid_: Achievement, credential (as an umbrella term)

**Award**:
A distinction or prize. It shares the Certifications & awards section with certifications.
_Avoid_: Achievement, honour

**Index plate**:
The Home-page portrait-shaped panel with the owner's photo, the index year, availability, focus, and location. It is a UI composition, not a content type.
_Avoid_: Profile card, bio box, Dossier

**Focus areas**:
The three interests shown on Home: computer vision, NLP, and deep learning. MLOps is a delivery practice, not a focus area.
_Avoid_: Specialties, domains, research interests
