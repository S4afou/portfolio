# Portfolio

A personal portfolio site for Medjahri Mohammed Safouane, an AI & Data Science engineering student, aimed at internship and PFE (final-year project) applications.

## Language

**Project**:
A body of work the site presents. Every Project gets a full page telling the story from problem to result; a Project may span more than one Repository.
_Avoid_: Case study, repo, codebase, portfolio entry

**Featured Project**:
One of the four Projects shown on Home. The other Projects are reachable through “Show all 6 projects” and the Projects index.
_Avoid_: Selected Project, main Project, flagship

**Repository**:
A Git code container on GitHub. It is a link target, never the unit the site presents.
_Avoid_: Repo, project, source

**Publication Status**:
Whether a Project’s code is publicly reachable, pending publication, or private.
_Avoid_: GitHub status, link status

**Education**:
Degrees and the baccalaureate, including the ESI-SBA preparatory and engineering cycles.
_Avoid_: Studies, schooling

**Experience**:
Professional roles and internships, including the CTS Arzew network internship and the Zenith Academy teaching role.
_Avoid_: Work history, career

**Leadership & extracurricular**:
Student-club offices and extracurricular responsibilities, kept separate from professional Experience.
_Avoid_: Activities, volunteering, clubs (as an umbrella term)

**Certification**:
A credential issued by an external body. Certifications and awards have their own About section, which stays hidden while the list is empty.
_Avoid_: Achievement, credential (as an umbrella term)

**Award**:
A distinction or prize. It shares the Certifications & awards section with certifications.
_Avoid_: Achievement, honour

**Dossier**:
The Home-page facts panel: location, availability, focus, and languages. It is a UI label, not a content type.
_Avoid_: Profile card, bio box
